Архитектура решения и стек технологий

ARCHITECTURE

В рамках курсового проекта реализован веб-сервис управления жизненным циклом и экологичностью данных страховой компании на базе Spring Boot и Spring Security с разграничением прав по ролям (OWNER, STEWARD, AUDITOR, ADMIN).

Реляционное хранилище PostgreSQL (Spring Data JPA) содержит каталоги наборов данных, правила хранения (retention_rules) и историю расчётов метрик ($V, D, S, Q$) и интегрального индекса $I$. Документоориентированное хранилище MongoDB (Spring Data MongoDB) используется для неизменяемого журнала аудита и резервных копий (FULL / INCREMENTAL) с контрольной суммой SHA-256. Пользовательский интерфейс выполнен на Thymeleaf, Tailwind CSS и Chart.js.
