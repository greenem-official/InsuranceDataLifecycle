Опыт работы со стеком и архитектура решения

В рамках курсового проекта реализовано веб-приложение на базе Spring Boot и Spring Security с разграничением прав по ролям (OWNER, STEWARD, AUDITOR, ADMIN). Реляционные данные наборов, правил хранения и истории метрик хранятся в PostgreSQL (Spring Data JPA), а журнал аудита и резервные копии с контрольной суммой SHA-256 — в MongoDB (Spring Data MongoDB). Пользовательский интерфейс построен на Thymeleaf, Tailwind CSS и Chart.js.
